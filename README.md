Task2 – Data Analysis with Python

This repository contains my **Task 2 project** completed as part of my Python/Data Analytics learning journey. The project demonstrates how to analyze data and create visualizations using Python.

## Project Objective

The objective of this task is to:

* Load and analyze a dataset using Python.
* Perform basic data analysis.
* Create different types of charts and graphs.
* Identify patterns, trends, and insights from the data.

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Features

* Data loading and preprocessing
* Handling duplicate values
* Finding unique and repeated elements
* Summary statistics
* Bar chart
* Line chart
* Pie chart
* Histogram
* Scatter plot

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/DEEPAKS110/Task2.git
```

2. Open the notebook in **Google Colab** or **Jupyter Notebook**.

3. Install the required libraries if needed:

```bash
pip install pandas numpy matplotlib seaborn
```

4. Run all cells in the notebook.
